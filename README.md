# code4crittersoncallapps.github.io

Org root GitHub Pages site. It exists only to serve `/.well-known/assetlinks.json` for the Android (Play Store) build of Critters on Call Gold (`com.sheehanhomestead.gold`).

Do NOT add folders named after project repos (gold, academy, critters-play, critters-on-call, ...); a folder here would shadow that project's site.

When Play App Signing is on, add the **app signing key** SHA-256 from Play Console (Setup > App integrity) to `sha256_cert_fingerprints` next to the upload key.
